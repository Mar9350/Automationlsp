      Install

      Load a LISP routine in AutoCAD, or run a Python tool.

      Try a tool in the current drawing.

      1. Save the .lsp file in a permanent folder, for example C:\ProCAD\LISP.
      2. In AutoCAD, type APPLOAD and press Enter.
      3. Browse to the folder and select the file.
      4. Click Load. If a security warning appears, choose Load Once.
      5. Click Close, type the command and press Enter.

      The tool stays loaded for this session only. You can also drag the .lsp file into the drawing area.

      Add the file to the Startup Suite once. AutoCAD loads it every time.

      1. Type APPLOAD and press Enter.
      2. Under Startup Suite, click Contents…
      3. Click Add…, select the .lsp file and click Open.
      4. Click Close, then Close again.
      5. Restart AutoCAD and test the command.

      Keep all ProCAD files in one folder. Don't load two versions of the same command, such as BLKCLEAN and BLKCLEAN_v2.

      The Python tools are packaged as .exe files. Python is not required.

      1. Copy the .exe to a permanent folder, for example C:\ProCAD\Tools.
      2. Double-click it to open the tool.
      3. Open the source file: an image for ImageToDXF, a DXF for the others.
      4. Choose the settings, run, and save with a new file name.
      5. Open the result in AutoCAD and review it.

      Close the DXF in AutoCAD before processing. Keep the original. Save outputs with a suffix such as _converted or _translated.

      01Unknown command

      Choose Load Once, or add the LISP folder to Trusted Locations.
